# Plugin Tag Filters

A plugin to customize the Plugins interface enabling tag-based filtering.

You can [test the filtering in your browser](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/georgestephanis/plugin-tag-filters/trunk/_playground/blueprint.json) using Playground. Try searching for a new plugin to install!

## Requirements

- WordPress 6.7+
- PHP 7.4+
